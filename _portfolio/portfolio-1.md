ArtiControlNet 是一个面向设计师的多智能体 AIGC 对话工作台，也是省级大学生创新项目「基于进化算法的条件扩散模型高效架构探究」的应用载体。用户以自然语言（可附参考图）提出需求，系统即可完成文生图、线稿生图（图像编辑）、图像问答三类核心任务，以及纯文本对话。系统架构严格分为前后端两层，无数据库。前端为 Vue 3 纯静态单页应用，提供对话交互、图片上传与任务轮询，会话历史保存在浏览器本地；后端为 FastAPI 无状态编排服务，用 LangGraph 实现"单跳分发"——Supervisor 主 Agent 仅做一次意图识别与工具选择，命中文生图、线稿生图、图像问答等子 Agent 后，子 Agent 直接调用外部云端模型 API 并将结果原样返回给用户，不再二次总结。生图统一走腾讯 TokenHub 的 hy-image-v3 模型（文生图与线稿生图共用一个接口），图像问答由 DeepSeek 视觉模型承担，完全不做本地推理。工程上以异步任务队列承载请求，提交即返回任务号、前端轮询取结果；后端为无状态、可静态化部署，前端可托管至 GitHub Pages。全部 API 密钥仅存在于后端环境变量，前端与仓库均不存放真实密钥。整体轻量、可移植，符合"无本地推理、无数据库、仅两层"的硬约束，也为后续多工具串联、流式输出等演进预留了扩展空间。
