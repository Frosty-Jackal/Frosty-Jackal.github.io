ArtiControlNet 是一个面向设计师的多智能体 AIGC 对话工作台，也是省级大学生创新项目「基于进化算法的条件扩散模型高效架构探究」的应用载体。我针对设计学专业学生使用软件辅助设计时存在的学习成本高、软件功能与实际设计流程不匹配等问题，通过用户调研梳理核心使用场景与需求，撰写PRD，并和Claude Code协同开发赋能设计的多智能体 AIGC 系统；产品采用简洁的对话式交互，降低 AI 工具使用门槛，并结合设计师实际工作流设计“线稿生图”等功能，实现 AI 能力与设计场景的深度结合；同时通过 API 接入AI生图等服务并搭建多智能体协作流程，在产品设计阶段同步考虑 AI 服务成本，采用按实际使用量计费的商业模式。同时，为支撑公网部署的实际场景，补充了登录认证与权限管理；并设计数据埋点，采集“人均AI服务调用次数”等关键数据，并搭建面板方便管理员根据用户数据驱动产品迭代。

我们的项目前端为 Vue 3 纯静态单页应用，提供对话交互、图片上传与任务轮询，会话历史保存在浏览器本地；后端为 FastAPI 无状态编排服务，用 LangGraph 实现"单跳分发"——Supervisor 主 Agent 做意图识别与工具选择，命中线稿生图、图像分析等子 Agent 后，子 Agent 直接调用外部云端模型 API 并将结果返回给用户。关于API选用，例如，生图模型走腾讯 TokenHub 的 hy-image-v3 模型。工程上以异步任务队列承载请求，提交即返回任务号、前端轮询取结果。全部 API 密钥仅存在于后端环境变量，前端与仓库均不存放真实密钥。整体轻量、可移植，符合"无本地推理、无数据库、仅两层"的硬约束，也为后续多工具串联、流式输出等演进预留了扩展空间。项目源码在https://github.com/Frosty-Jackal/ArtiControlNet。如需订购该产品，请联系我以获取。
