Abstract—Diffusion-based multi-reference face restoration aims to recover a high-quality face image from a degraded input using several reference images of the same identity. However, existing methods are limited in restoration fidelity and identity preservation. We discover that the shared-attention mechanism lacks explicit supervision, causing its attention routing to fail
under cross-pose references; and that the rich multi-scale features computed by the reference branch are largely underutilized, leading to a waste of useful computational resources. We propose PAIRS, a single-step face restoration framework that addresses both issues. First, we design Identity-Consistent Attention Learning, which employs a self-supervised loss that enforces attention consistency between reference images at semantically corresponding regions, thereby strengthening cross-pose robustness with no need for manual annotation. Second, we propose Permutation-Invariant Identity Encoding, which projects reference features into an unordered set to extract identity-distinctive representations that provide robust guidance for the restoration branch. Extensive experiments demonstrate that PAIRS achieves superior performance over existing methods on restoration quality and identity preservation.
